# Sleep Rescue - Google Sheets Edition

Google Sheet에 `records`라는 탭을 만들고 첫 행에 아래 열을 입력하세요:

user_id | 날짜 | 수면시간 | 피로도 | 스마트폰(분) | 늦은 카페인 | 낮잠 | 규칙적 기상 | Rescue Score

Google Sheet를 Google Cloud Service Account 이메일에 '편집자'로 공유하세요.
Service Account 자격증명은 GitHub에 올리지 말고 Streamlit Community Cloud의 App settings > Secrets에 저장하세요.
